    • Parallel Job Review: Hold Ctrl+Click (Windows/Linux) or Cmd+Click (macOS) on any job title or 🔬 STUDIO button in Mission Control or Jobs Pipeline to inspect multiple jobs in separate browser tabs simultaneously.

    4. SECURITY ARCHITECTURE & CLI ZERO MAINTENANCE
    • Flexible Deployment: Run directly on Railway Direct with full-screen WEB_API_KEY cookie login (zero proxy compute credits), or place a private static UI + Deno Edge Proxy in front.
